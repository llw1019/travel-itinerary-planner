# 問卷題庫

分成 A–G 七大類。每類底下列出建議問題與選項,設計時請對照 `ask_user_input_v0` 的限制:單次最多 3 題、每題最多 4 個選項。可依對話情境合併或跳過不相關題目,這裡的分類與選項是起點,不是必須逐字照問的腳本。

若某題答案超過 4 個常見選項(例如目的地城市、國家),不要硬塞進 options,改用一般文字提問,或列出最常見的 3 個 + 「其他(請說明)」。

> **通用原則,適用 B–G 全部類別**:只要同行者不只一人、且身分/角色不同(老闆、老闆的配偶、特助、客戶等),**任何「偏好類」問題都不能預設整團答案一致**——不只是 B 類的體力/飲食,艙等(C)、房型與住宿等級(D)、步調與活動內容偏好(E)、緊急聯絡人(G)全部都可能因人而異。問完人數與組成後,針對後續每一類偏好,先確認「這幾位同行者在這件事上的需求是否相同」,相同才套用同一組答案;不同就分別記錄,並在最終確認清單與行程文件裡清楚標示是哪一位的安排,不要籠統寫成單一人稱(例如「老闆的行程」)卻其實混雜了不同人的需求。

## A. 基本行程資訊

> **這一類全部都要在問卷中明確問到、明確拿到使用者的回答,不可以從對話裡先前提過的範例、假設情境、或使用者隨口帶到的字詞去推定。** 即使先前對話中(例如使用者說「先跑個範例看看」時舉的例子)提過某個目的地,只要使用者本人沒有在這次的問卷流程裡親口確認,就必須當作未知,重新詢問。目的地問錯,後面排的整趟行程都是廢的,這是最不能省略的一步。

- 目的地(國家/城市):開放式提問,不要用選項卡片預設答案,務必等使用者明確回覆
- 國內 / 國外
- 出發與回程日期(或總天數)
- 本次行程事由:商務出差 / 純旅遊 / 接待貴賓 / 獎勵旅遊 / 其他
- 出發地(城市/機場)

## B. 對象資料

> 人數與組成問完後,先確認「這幾位同行者的體力/步行偏好、飲食限制是否一致」(見上方通用原則)。

- 人數與組成:單人 / 2-4 人小團 / 5 人以上團體,並請使用者說明每位同行者的身分角色(例如「老闆+老闆娘+特助」)
- 身分定位:公司高階主管 / 一般員工 / 客戶或貴賓 / 家庭旅遊
- 是否常走動、體力狀況:習慣長時間步行 / 偏好較少步行 / 需要無障礙安排
- 飲食限制或偏好:無特殊限制 / 素食 / 特定禁忌(請說明) / 需要正式宴請規格

## C. 交通
- 航班艙等偏好(留意是否全員同艙等,見上方通用原則):經濟艙 / 豪華經濟艙 / 商務艙 / 頭等艙
- 航班偏好:直飛優先 / 可接受轉機 / 時段有特定要求(請說明)
- 機場接送:需要司機接送 / 自行前往 / 尚未決定
- 若需要司機:是否要提前通知固定座車(需要,請提供聯絡窗口 / 需要,尚未有固定司機 / 不需要)
- 市內交通方式:全程包車 / 大眾運輸為主 / 步行+少量計程車 / 混合安排由你建議

## D. 住宿
- 星級/等級:五星級或同等 / 精品/設計旅店 / 商務型 / 依預算彈性
- 位置偏好:市中心 / 鄰近主要行程地點 / 鄰近機場方便進出 / 交給你安排
- 房型與間數需求:單人房/套房/是否需分房,並確認是否所有同行者住同一飯店同等級,或有人需要分開安排(見上方通用原則)

## E. 行程規劃類型
- 整體步調(留意是否全員一致,見上方通用原則):緊湊(盡量排滿) / 適中 / 悠閒(保留大量彈性時間)
- 室內外活動比例:偏好室內為主 / 室內外均衡 / 偏好戶外為主 / 交給你依天氣建議
- 戶外活動接受度:可接受高溫/日曬 / 需要遮蔭或室內備案 / 雨天需完整備案
- 每日作息:早出晚歸 / 晚起悠閒 / 依當天行程彈性調整
- 內容偏好(可複選,留意每位同行者想要的類型是否不同):自然景觀、文化古蹟、美食、購物、休閒放鬆、商務會談安排

## F. 預算
- 每人每日預算區間,或總預算(開放式提問,或給 3 個級距讓使用者選 + 其他)
- 價位接受度:高端不設限 / 中高階 / 大眾價位 / 依項目彈性(例如住宿高端但餐飲彈性)

## G. 特殊需求
- 保密 / 低調需求:需要低調安排(避免曝光行程) / 一般安排即可
- 緊急聯絡人(若同行者不只一人,確認是否每人各自提供,見上方通用原則) / 隨行醫療需求(若使用者主動提供醫療相關資訊,規劃時轉化為「步調寬鬆、備妥休息時間」等中性安排描述,不要在存檔或行程文件中記錄診斷或病名)
- 保險安排:需要協助確認 / 已自行處理
- 其他禁忌或務必避開的事項(自由文字)

## 建議分輪範例

實際分輪要依對話上下文彈性調整,以下僅為起點示例:

- 第 1 輪:A 類(目的地/日期/事由/出發地)
- 第 2 輪:B 類(人數、身分、體力狀況、飲食)
- 第 3 輪:C 類(艙等、航班偏好、接送、司機通知)
- 第 4 輪:D + E 類(住宿等級與位置、步調、室內外比例)
- 第 5 輪:E(續) + F 類(內容偏好、預算)
- 第 6 輪:G 類(保密、緊急聯絡、其他禁忌)— 這類問題較敏感,用開放式文字問即可,不一定要用選項卡片
